# 超长周期排班：候选方向详细拆解与第一轮尝试（2026-10-22）

统一记号（单点模型推广而来）：
- 时间按班次分格。机器人值完第 k 班要隔 g(φ_k) 格才能再上岗，相位 φ 沿维修超周期推进；一个超周期内间隔之和为 S，班数为 L，平均间隔 ā = S/L。
- K = 值班点数，每格需要 K 台不同机器人。速率下界：N ≥ ⌈K·ā⌉。
- "同型" = 所有机器人参数相同。"全新启动" = 所有机器人第 0 格都满额度、同相位。

---

## D1 同型机器人的最少台数公式

**是什么。** 只有一种机器人，问至少要几台。速率下界 ⌈ā⌉ 告诉我们"平均够用"，但维修是一块一块的，几台同时大修就会断档，所以真实最少台数 N* 可能比下界多。

**为什么有意思。** 文献（pinwheel covering）只问"给定这些机器人能不能排"，没问"至少要几台"。答案如果能写成公式，就是一条干净的定理，也是 D1b（多型号）的基础。

**数学问题。** 给定间隔序列 g，求 N*(g) − ⌈ā⌉ 的值（目前观测为 0、1，极少为 2），并刻画什么时候为 0。
- 已知一端：ā 为整数（零余量）时，可行 ⇔ 循环群 Z_S 能被 N 个"上岗时刻集合"的平移恰好铺满（我们的定理，常数周期时退化为 Kawamura–Soejima 定理 18）。
- 待做：余量为正时的条件。

**尝试方法。** 从两段间隔 [x, y] 起，x、y 取 1–30 全部精确计算，画表找分界线。

**D1b 多型号。** 每种型号一个间隔序列，问混用什么时候比只用一种更省。现有实例上混用不更省（L2 例外，打平）。

---

## D2 多地值班：共享 vs 专点分组 ★

**是什么。** K 个值班点。两种用法：
- 专点分组：机器人分成 K 组，每组固定守一个点，需要 K·N*(1) 台；
- 共享：任何机器人可以去任何点，需要 N*(K) 台。
问：共享能省多少？

**为什么有意思。** 覆盖版文献里没有"每天需要 K 个"。如果共享的损失（离下界的差）不随 K 增长，而分组的损失随 K 线性增长，就是一个漂亮的结论："共享把取整损失摊薄了"。

**数学问题。** 证明或否定：N*(K) − ⌈K·ā⌉ 有一个与 K 无关的上界 c(g)；而 K·N*(1) − ⌈K·ā⌉ 随 K 线性增长（当 N*(1) > ā 时）。

**第一轮结果（全新启动，精确）。** 见文末表 D2。

## D3 启动代价与有限期（turnpike）

**是什么。** 两个相关问题：
1. 启动代价：全新机队同时上线（所有机器人同相位），比"相位已经错开"的稳态多要几台？之前 47 个失败例里 27 个只是因为同相位启动。
2. 有限期与无限期：时域 H 短时，新机器人满额度，能少用几台；H 多长以后，有限期最优就等于无限期最优？这个分界 H0 叫 turnpike 点。

**为什么有意思。** pinwheel 文献的排班定义在整个整数轴上，没有"开局"。实际排班都有开局。

**尝试方法。** 统计"全新 − 稳态"的分布；对固定实例画 N*_H 随 H 的曲线，找 H0，看能否用超周期长度估计。

---

## D4 场景建模：允许提前维修 ★

**是什么。** 现在维修是"工时不够才强制触发"。允许机器人在一班结束后**主动选择提前维修**（任一级），会怎样？

**为什么有意思。** 文献里每个 agent 的周期是给定的；这里 agent 可以自己选周期模式。这是"场景要素改变数学结构"的一个具体例子，正对应你说的场景影响建模。

**数学问题。**
- 单台机器人：允许提前维修后的最优长期间隔 ā* = 单机状态图上的最小平均环（Karp 算法），速率下界变为 ⌈K·ā*⌉。
- 整体：提前维修能否让最少台数达到速率下界？

**第一轮结果。** 见文末表 D4。

## D5 循环周期的密度阈值

**是什么。** 机器人参数各不相同时，已知结论（Kawamura & Kobayashi 2026、Mishra 2026）：周期固定时，只要 Σ 1/a_i ≥ 1.264 就一定排得出来。问：周期按维修相位循环时，这个阈值变成多少？大概率取决于周期的波动程度（大修间隔 / 平均间隔）。

**尝试方法。** 随机生成实例，搜"密度最大但仍排不出来"的实例族；再借用文献里的"折叠 + 取整到有限实例 + 计算机验证"框架。难度最大，放第二轮。

---

## D6 不等长班次

6h 和 10h 型号混用时，班次不落在统一格子上。可写成"实数周期"，对照实数周期 pinwheel 的结论（Fujiwara 等 2025；Kawamura、Kobayashi、Kusano 2025）。放后。

## D7 复杂度

同型、循环周期时，最少台数能否多项式时间算出（异构时已知强 NP 难）。依赖 D1 的结构，放后。

**读法：**
1. 提前维修几乎不提高单台机器人的效率：ā* 大多等于 ā，只有 2 型略降。
2. 但它在 7 个例子里把最少台数降了 1，**而且所有已解出的例子都恰好达到速率下界**（L1/2 型 K=1 除外：⌈7⌉=7 仍要 8）。
3. 机制：提前维修的价值不在"修得更勤"，而在"错峰"——把各台机器人的大修时间错开，消除同步撞车。
4. 猜想：允许提前维修（或更一般地，允许选择维修时机）时，N* = ⌈K·ā*⌉ 在绝大多数情况下成立；例外的结构（如 L1/2 型 [3,3,15]，零余量且不能铺砌）需要刻画。

**读法：**
1. 共享比分组省的台数随 K 增长：K=5 时省 1–3 台。
2. 共享离速率下界的差始终很小（0–2），没有随 K 变大；分组离下界的差 = K·(N*(1) − ā)，随 K 线性增长。
3. 猜想：N*(K) − ⌈K·ā⌉ ≤ c(g)，c 与 K 无关；因此 N*(K)/K → ā（多地共享时取整损失被摊薄）。
4. 与 D4 叠加：允许提前维修时，K=2 的三个例子（L1/0 型、L2/0 型、L3/0 型）都恰好达到下界。

## 第一轮的两个猜想（待证明）
- **猜想 A（共享摊薄）：** 同型、K 个点：N*(K) ≤ ⌈K·ā⌉ + c(g)，c 与 K 无关。
- **猜想 B（错峰补足）：** 允许选择维修时机时，N* = ⌈K·ā*⌉，例外只出现在零余量且不能平移铺砌的结构里。

两者合起来的含义：取整损失（离速率下界的那 1–2 台）来自"刚性 + 同步"，多点共享和维修时机的灵活性都能消除它。

# 第二步：两个猜想与文献对照（2026-10-22 晚）

## 相关文献
- **Windows scheduling 多信道**（打包版，异构页面，Bar-Noy & Ladner 2003；Bar-Noy、Ladner、Tamir 2007）：总密度 h 时离线需要 h + O(ln h) 个信道，在线 h + O(√h)；周期两两整除时恰好 h。附加项随 h 增长。
- **Pfair**（Baruah、Cohen、Plaxton、Varvel，Algorithmica 1996）：打包、权重型周期任务，总权重 ≤ m 就能在 m 台处理器上公平调度（每个任务的滞后严格在 (−1, 1) 内）。
- 覆盖版文献（Kawamura 等）：只有每天一个 agent，周期固定。

## 定理 A（多地共享的摊薄定理，稳态）——已证明
记号：同型机器人，间隔序列 g = (g1,…,gL)，S = Σg，ā = S/L；A = {0, g1, g1+g2, …} ⊂ Z_S；K 个值班点，N*(K) 为稳态（定义在整个整数轴上）最少台数。

1. **K 为 L 的倍数时恰好达到下界：** N*(mL) = mS = mL·ā。
   - 构造：S 台机器人，第 t 台（t = 0,…,S−1）的工作时刻为 t + A + SZ（按 g 循环）。对任意 x ∈ Z_S，满足 x ∈ t + A 的 t 恰有 |A| = L 个，所以每格恰好 L 台不同机器人。重复 m 份即得 K = mL。
   - 下界：速率下界 N ≥ K·ā。
2. **次可加：** N*(K1 + K2) ≤ N*(K1) + N*(K2)（两组机器人分别守两组值班点）。
3. **常数附加项：** 写 K = qL + r（0 ≤ r < L），则 N*(K) ≤ qS + N*(r)，于是
   N*(K) − K·ā ≤ c(g) := max_{0≤r<L} (N*(r) − r·ā)，与 K 无关；并且 N*(K)/K → ā。
4. **对比专点分组：** K·N*(1) − K·ā = K·(N*(1) − ā)，只要 N*(1) > ā 就随 K 线性增长。

数值核对（`thmA.py`）：[3,10]、[2,9]、[4,4,5]、[2,2,5]、[3,5,2,6]、[4,4,5,4,9]（L3 的 0 型）、[3,3,15]（L1 的 2 型）在 K = L、2L 时，构造都使每格恰好 K 台，精确搜索也确认可行。注意 [3,3,15] 单点时达不到下界（零余量且不能铺砌），但 K = 3 时恰好达到——多地共享消除了单点的刚性。

**与文献的区别：** windows scheduling 的附加项随密度增长（ln h），这里同型、循环周期时附加项是常数，而且在 L 的倍数处为 0。

**未解决：** 全新启动时的版本。数值上全新启动比稳态多 1–2 台（如 [3,10] 在 K=2、4 时为 14、27，稳态为 13、26），这正是 D3 的启动代价。

## 猜想 B（允许提前维修 ⇒ 达到下界）
- 文献里没有对应结论；最接近的是"实数周期"覆盖版（agent 在任意 ⌊l·a⌋ 天内至多 l 次，按平均节奏约束），可视为"节奏可调"的一种形式。
- 证明难度明显高于 A：需要说明提前维修带来的相位调整足以消除同步。先作为数值猜想保留，并刻画例外（零余量且不能铺砌）。

## 判断
- 定理 A 已经可以写成完整证明，是目前最扎实的成果。
- 猜想 B 与 D3（启动代价）可以合并研究："灵活维修时机能否消除启动代价"。
