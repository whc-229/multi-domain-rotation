# 超长周期排班的数学探索：数值证据（2026-10-22）

班次槽模型（同型机器人，槽间隔序列 g 来自维修超周期；ā = 周期内平均间隔；K = 值班点数）。
依赖同级目录 `../启发式验证/` 的 slotmodel.py、kpost.py（运行时把本文件夹脚本复制过去，或把该目录加入 PYTHONPATH）。

- `conj_rate_gap.py N K`：随机生成 N 个间隔序列，求全新启动时的精确最少台数 N*，与速率下界 ⌈Kā⌉ 比较。
  K=1（250 个）：N*−⌈ā⌉ = 0 有 146 个，= 1 有 103 个，= 2 有 1 个。
- `conj_steady_vs_fresh.py`：K=1 中 N=⌈ā⌉ 全新启动不可行的情况，再看允许任意初始相位（稳态）是否可行。
  结果：全新可行 146；全新不可行但任意相位可行 27（启动同步造成）；任意相位也不可行 20（其中 19 个余量 ⌈ā⌉−ā = 0）；未决 57。
- 零余量时的平移铺砌判据，在 [2,6]、[1,3]（可铺砌、可行）和 [2,4]、[4,8]、[3,3,6]、[6,12]、[5,6,4]（不可铺砌、不可行）上与精确搜索一致。
