## 0. 结论先行

**稳态（相位已错开，允许等待）**

1. 【证明】最少台数 N(K) 与流体下界 ⌈Kā⌉ 的差 c(K) 沿 K 的每个模 L 剩余类单调不增，所以存在 K₀，使 K ≥ K₀ 时 N(K+L) = N(K) + S（最终周期性）。K₀ 可以大于 1。
2. 【证明】零余量（Kā 为整数）时，N(K) = Kā 当且仅当上岗时刻集合 A 在 Z_S 上做 K 重平移铺砌。这把"能不能恰好达到下界"变成了**平移铺砌理论**中的问题。K = 1 时可以直接用 Coven–Meyerowitz 的分圆多项式判据（Kolountzakis–Matolcsi 的 Z_N 局部版本）：L 至多含两个不同素因子时，判定可以在 S 的多项式时间内完成。
3. 【证明】L = 2 的闭式：N(K) = ⌈K(a+b)/2⌉ + [a、b 都是偶数，2-adic 赋值不同，且 K 为奇数]。
4. 【证明】剩余系拉伸引理推出 c(1) ≤ L − 1，并且对所有 K 有 c(K) < L(L − 1)。**这个差只依赖每个超周期的班数 L，与间隔长短无关。**固定模式下的初等界（Bartholdi 类）给出的差最大可达 S。
4′. 【证明 + 机证】两类显式构造（多超周期"剩余均衡拉伸"、多类"混合拉伸"），加上对有限个余数类的检查，证明了 **L ≤ 4 时对所有间隔序列和所有 K 都有 N(K) ∈ {⌈Kā⌉, ⌈Kā⌉ + 1}**（猜想 C1 在 L ≤ 4 上成立）。L = 3 时还证明了 C2：W ≥ 2 ⇒ N(K) = ⌈Kā⌉。L = 5 只剩一个余数类的一个剩余类。在 628 组图谱上，这个构造上界有 97% 恰好等于真实最优。
5. 【数值 + 否定】628 个图谱组合加 160 个定向搜索组合里都有 c ∈ {0, 1}。猜想 C2 原来说"正余量时 c = 1 只在 W = ⌈Kā⌉L − KS = 1 时出现"，它在 L ≤ 3 上成立（已证），但在 L = 5 上**被严格否定**：[5,2,2,11,3] 在 K = 1 时 W = 2，用状态图穷尽判定，5 台在任何周期下都不可行，6 台可行。本轮新增的"状态图精确判定"不依赖周期上限，可以把小实例上 c = 1 的数值结论变成严格结论。
6. 【数值】零余量下"可以恰好达到下界的 K"构成一个加法半群。L = 6 时出现了 ⟨2, 3⟩ = {2, 3, 4, …} 这种非循环形状（282 例），例如 [1,1,1,2,2,5]：1 个点不能铺满，2 个点和 3 个点都能。

**全新同相位启动**

7. 【证明 + 机证】启动代价一般随 K **线性**增长，不是常数。推进方案第 4 步的"离散 turnpike：N_fresh − N* 有界"**被否定**。显式反例族 g = [1, 2k]：用人工可核对的槽权重证明 N_fresh(K) ≥ K(S² + 1)/(2S)，而稳态是 ⌈KS/2⌉。
8. 【机证】对 25 个序列给出精确有理对偶证书 α_H，作为 N_fresh(K)/K 的下界（对所有 K 成立）。例如 [4,4,5]：33/7 > 13/3；[3,10]：73/11 > 13/2。
9. 【证明】零启动代价的充分条件：A(z) 整除 1 + z + … + z^{S−1}，且商的系数非负（A 的平移可以不越界地恰好铺满区间 [0, S)）。【数值】这个条件也是必要的：478/478 一致（其中 25 例满足）。整数版本对应 de Bruijn 的混合进制数系。
10. 【数值 + 否定】整数值在 280 组中有 273 组满足 N_fresh(K) = max(⌈α_fresh·K⌉, N(K))。其余 7 组恰好多 1，例如 [1,2,6] 在 K = 6 时 ⌈αK⌉ = 19，实际是 20（由 ILP 上下界夹定）。所以"取整即精确"不普遍成立，修正为猜想 N_fresh ∈ {⌈αK⌉, ⌈αK⌉ + 1}。

**提前维修、随机维修、分组**

11. 【机证】允许提前大修以后，[3,10]、[2,9]、[4,4,5]、[2,2,5]、[4,6,5,4]、[2,6,3] 的全新启动代价对 K = 1…10 全部消失，台数恰好是 ⌈Kā*⌉。[3,5,2,6]、[4,4,5,4,9]、[3,6,3,6,9] 仍有线性代价，但斜率变小。
12. 【数值】大修时长随机时，满足缺岗率 ≤ 10⁻³ 所需的超额台数按 √K 增长：[3,10] 大修 10±2 时，超额/√K 在 K = 4…128 上稳定在 1.8–2.1；确定性情形同一策略的超额恰好为 0。这支持了"√N 障碍来自随机性，而不是周期性"的桥接论断。[2,2,5]、[4,4,5] 的结果相同（[4,4,5] 用更长时域、3 个种子复核过）。
13. 【证明】分组损失 ≤ (m − 1) + Σ c(K_i)，在实例上可以取等。

## 1. 模型与记号

- 时间按班次分格 t ∈ Z（稳态）或 t ∈ Z≥0（全新启动）。K 个值班点，每格恰好需要 K 台**不同**机器人。
- 同型机器人的间隔序列 g = (g₀, …, g_{L−1})，g_i ≥ 1。机器人在相位 φ 值完一班后，要过 g_φ 格才能再上岗，同时相位变为 φ+1 (mod L)。到点以后可以**等待**任意格。
- S = Σg_i（超周期长度），ā = S/L（平均间隔），A = {s₀ = 0, s₁, …, s_{L−1}}，其中 s_i = g₀ + … + g_{i−1}，表示一个超周期内的上岗时刻集合。多项式记号 A(z) = Σ_{a∈A} z^a。
- 四种设定：
  - **W**（稳态、允许等待）：N(K) 是存在双向无穷排班时的最少台数。状态有限，所以等价于存在周期排班。
  - **F**（固定模式）：不许等待，每格覆盖 ≥ K。这就是循环覆盖整数规划。
  - **Fr**（全新启动）：N 台机器人在 t = 0 全部处于相位 0、就绪；只排 t ≥ 0。
  - **R**（允许提前大修）：在任意相位 φ ≠ L−1 值完一班后，可以选择直接进入大修：间隔 g_{L−1}，回到相位 0。
- 记 c(K) = N(K) − ⌈Kā⌉，c* = sup_K c(K)，W(K) = ⌈Kā⌉L − KS ∈ [0, L)（"余量"按班次计）。零余量就是 W = 0。

## 2. 稳态（允许等待）

### 2.1 流体下界【证明】

**命题 1.** 任何设定下都有 N ≥ ⌈Kā⌉。

证：一台机器人连续 L 班覆盖完整一个相位循环，跨度至少 S，所以在长度为 T 的时间窗里最多上岗 L(T/S + 1) 次。窗内总需求为 KT ≤ N·L(T/S + 1)。令 T → ∞ 得 N ≥ KS/L，再取整。∎

### 2.2 轨道构造与次可加性【证明】

**命题 2.** (i) N(mL) ≤ mS；(ii) N(K₁ + K₂) ≤ N(K₁) + N(K₂)。

证：(i) 在每个偏移 b ∈ Z_S 放 m 台机器人，都按 A 不等待地循环。格 x 被偏移 b 覆盖当且仅当 x − b ∈ A，恰有 L 个 b，所以每格 mL 台。(ii) 两套互不相交的机队直接合并。∎

### 2.3 单调性与最终周期性【证明】

**定理 3.** c(K + L) ≤ c(K)。因此 c 沿每个模 L 剩余类单调不增，存在 K₀，使 K ≥ K₀ 时 N(K + L) = N(K) + S。此外 c(mL) = 0，且 c* < (L − 1)(c(1) + 1)。

证：由命题 2，N(K+L) ≤ N(K) + N(L) ≤ N(K) + S，又 ⌈(K+L)ā⌉ = ⌈Kā⌉ + S，所以 c(K+L) ≤ c(K)。非负整数的不增序列最终是常数，L 个剩余类各自稳定以后取最大的稳定点为 K₀。对 k < L，N(k) ≤ k·N(1) = k(⌈ā⌉ + c(1))，所以 c(k) ≤ k(c(1) + ⌈ā⌉ − ā) < k(c(1) + 1)。再由单调性推到所有 K。∎

- 推论：只要算出 K₀ 以前的值，K 按二进制给出时 N(K) 可以 O(1) 查表加周期延拓得到。
- K₀ 可以大于 1：[3,7,5,4] 的 c(1) = 1，c(5) = 0。注意单调性**不能**给出 K₀ 的上界，因为某个剩余类可能很晚才下降。实测各例的 K₀ ≤ L + 1。

### 2.4 零余量 ⇔ K 重平移铺砌【证明】

**定理 4.** 设 Kā ∈ Z。则 N(K) = Kā 当且仅当存在 B: Z_S → Z≥0，使对所有 x ∈ Z_S 有 Σ_{a∈A} B(x − a) = K（A 在 Z_S 上 K 重平移铺砌）。

证：(⇐) 在偏移 b 放 B(b) 台机器人，都按 A 不等待地循环。覆盖数为 Σ_a B(x − a) = K，台数为 Σ_b B(b) = KS/L（两边对 x 求和：KS = L·ΣB）。
(⇒) 取最优周期排班，再取公共周期 Π，使每台机器人的轨迹都以 Π 为周期（机器人之间的置换有限，可以做到）。机器人 r 在一个 Π 内上岗 n_r 次。周期性要求它走完整数个相位循环，所以 n_r = L·j_r，并且 Π = j_r·S + w_r，其中 w_r 是它在一个 Π 内的总等待时间。从不上岗的机器人 j_r = 0，w_r = Π。恰好覆盖要求 Σ_r n_r = KΠ，于是 KΠ = L·Σ_r (Π − w_r)/S，即 Σ_r w_r = NΠ − KΠS/L = 0（因为 N = KS/L）。所以没有机器人等待，每台都在 b_r + A + SZ 上岗。令 B(b) = #{r : b_r ≡ b}，就得到 K 重铺砌。∎

> 直观地说，零余量时一秒钟的等待都浪费不起，排班被迫变成纯粹的平移铺砌。等待的作用只在正余量时出现。

**推论 4.1（K = 1 的分圆判据）。** 设 L | S。记 S_A^S 为满足 p^k | S 且 Φ_{p^k}(z) | A(z) 的素数幂集合。条件为：
- (T1^S) ∏_{s∈S_A^S} Φ_s(1) = L；
- (T2^S) 若 s₁, …, s_m ∈ S_A^S 是不同素数的幂，则 Φ_{s₁⋯s_m} | A。

由 Kolountzakis–Matolcsi（Theorem 3.1，Coven–Meyerowitz 判据的 Z_N 版本）：T1^S 且 T2^S 推出 A 铺满 Z_S；A 铺满 Z_S 推出 T1^S；若 L 至多含两个不同素因子，铺满还推出 T2^S。所以在这个范围内，**N(1) = ā ⇔ T1^S ∧ T2^S，判定时间是 S 的多项式**。L 是素数幂时 T2 自动成立，判据简化为"恰好有 α 个 p^k | S 使 Φ_{p^k} | A"（L = p^α）。
- 检验：L = 2 时 A(z) = 1 + z^a，含有的素数幂分圆因子只有 Φ_{2^{v₂(a)+1}}，判据化为 2^{v₂(a)+1} | S，即 v₂(a) = v₂(b)，与定理 5 吻合。
- 数值：随机图谱里 30 例零余量 K = 1 全部一致；穷举 L = 3、4、5（S ≤ 24 或 20）和 L = 6（S ≤ 24）的全部零余量序列，分圆判据与"直接解铺砌整数规划"的结果没有出现不一致。
- L 含三个以上不同素因子（最小为 L = 30）时，T2 的必要性是开放问题（Coven–Meyerowitz 猜想），实际排班中 L 不会这么大。

**推论 4.2（水平半群）。** Λ(A) = {K : A 在 Z_S 上 K 重可铺} 对加法封闭，包含 L·N。零余量时 N(K) = Kā ⇔ K ∈ Λ(A)。穷举（K ≤ L）得到的形状如下：

| L | Λ 的形状及序列数 |
|---|---|
| 3 | N：75；3N：185 |
| 4 | N：149；2N：255；4N：457 |
| 5 | N：74；5N：930 |
| 6 | N：253；⟨2,3⟩：282；2N：608；3N：2813；6N：2783 |

L = 6 时的 ⟨2,3⟩ 例子如 [1,1,1,2,2,5]、[2,2,5,5,5,5]：1 个点时离下界差 1，2 个点以上都能恰好达到下界。Steinberger（2005）证明了 Z 上的水平半群可以需要任意多个生成元，所以一般情况下"哪些 K 能恰好达到下界"的结构可以很复杂。这是本问题和铺砌理论的第二个接口。

### 2.5 L = 2 的闭式【证明】

**定理 5.** g = [a, b]，S = a + b。N(K) = ⌈KS/2⌉ + 1，当且仅当 a、b 都是偶数、v₂(a) ≠ v₂(b)、且 K 为奇数；其余情形 N(K) = ⌈KS/2⌉。

证：
- K 为偶数：由命题 2(i)，N = KS/2。
- 下面设 K 为奇数，先看 S 为偶数（零余量，a、b 同奇偶）。由定理 4，问题化为 {0, a} 在 Z_S 上的 K 重铺砌。以 Z_S 为顶点、{x, x+a} 为边，得到若干个长 ℓ = S/gcd(a, S) = (a+b)/gcd(a,b) 的圈。平移 x 覆盖边 {x, x+a} 的两个端点，所以 K 重铺砌就是给圈上的边赋非负整数权，使每个顶点的两条边权和为 K。沿圈走，权值交替为 β、K − β，ℓ 为奇数时必须 2β = K，而 K 是奇数，矛盾。所以可铺 ⇔ ℓ 为偶数。
  - a、b 都是奇数：gcd 为奇数，a + b 为偶数，ℓ 为偶数，可铺。
  - a、b 都是偶数且 v₂ 相同：v₂(a+b) > v₂(gcd)，ℓ 为偶数，可铺。
  - a、b 都是偶数且 v₂ 不同：v₂(a+b) = min(v₂a, v₂b) = v₂(gcd)，ℓ 为奇数，不可铺，N ≥ KS/2 + 1。上界：把模式拉伸成 [a+1, b+1]（每班后多等 1 格），两段都变成奇数，周期 S+2 下可铺，1 个点用 (S+2)/2 台；其余 K−1 个点（偶数个）用轨道构造。合计 KS/2 + 1。
- K 为奇数且 S 为奇数（正余量）：a、b 一奇一偶。把偶数那段拉长 1，两段都成奇数，周期 S+1 下可铺，1 个点用 (S+1)/2 台；其余 K−1 个点用轨道构造。合计 (KS+1)/2 = ⌈KS/2⌉，等于下界。∎

数值核对：a ≤ b ≤ 8、K = 1…4 共 144 组，网络整数规划结果与公式 0 处不一致。

### 2.6 剩余系拉伸引理与"只依赖 L"的上界【证明】

**引理 6.** 设 g′ ≥ g（逐分量），M = Σg′ 且 L | M，并且 g′ 的部分和 A′ 两两模 L 不同余。则 N(K) ≤ K·M/L。

证：在偏移 0, L, 2L, …, M − L 各放 1 台机器人，都按 g′ 循环（在相位 i 额外等 g′_i − g_i 格）。格 x ∈ Z_M 被偏移 b 在第 i 班覆盖，当且仅当 b + s′_i ≡ x (mod M)。b 取遍 LZ_M，A′ 是模 L 的完全剩余系，所以 (b, i) 唯一：i 由 x − s′_i ≡ 0 (mod L) 唯一确定，然后 b 唯一确定。1 个点用 M/L 台，K 个点复制 K 份。∎

**推论 6.1.** 取步长 u ∈ Z_L^×，令 s′_i ≡ i·u (mod L)，最小拉伸量为 e_i = (u − g_i) mod L。记 E_u = Σ_i e_i，则 M = S + E_u 自动被 L 整除，并且
  N(1) ≤ (S + E_u)/L，c(1) ≤ min_u E_u/L ≤ L − 1。
结合定理 3 得 c* < L(L − 1)。**这个上界只依赖 L，与间隔大小无关。**固定模式下的初等界 N_F ≤ S⌈K/L⌉ 给出的差可以达到 S 这个量级，比如 [3,10] 是 13。

**推论 6.2（等差族）。** g = [c, …, c, G]（c 重复 L−1 次）且 gcd(c, L) = 1 时，取 u = c，只有最后一段需要拉伸，M 是 ≥ S 的最小 L 倍数，所以 N(1) = ⌈ā⌉。

**命题 6.3（L ≤ 3 时 c(1) ≤ 1）。** 由推论 6.1，c(1) ≤ (E_u − W(1))/L，所以只要存在单位 u 使 E_u ≤ W(1) + L，就有 c(1) ≤ 1。E_u 和 W(1) 只依赖各 g_i mod L。逐一检查余数模式：L = 2 的 4 种、L = 3 的 27 种全部满足；L = 4 的 256 种中有 6 种不满足（如 (0,0,2,2)）；L = 5 的 3125 种中有 260 种不满足。因此：
- L = 3 时对**所有**间隔序列 c(1) ≤ 1，再由定理 3 的单调性，**K ≢ 2 (mod 3) 时 c(K) ≤ 1**（C1 在这两个剩余类上成立）。K ≡ 2 (mod 3) 时，用 N(2) ≤ 2N(1) 只能得到 c(2) ≤ 3，需要新的构造（下面的引理 6′ 和定理 6.4 补上了）。例如 [3,3,15] 的 N(2) = 15，而 2N(1) = 16。
- L ≥ 4 时，单个超周期的剩余系拉伸不够用。下面的多超周期版本补上了大部分情形。

**引理 6′（多超周期剩余均衡拉伸）【证明】.** 把 g 重复 j 次得到 jL 个间隔，逐个拉长为 g″ ≥ g，总长为 M，并要求 L | M，且 jL 个部分和 s″_0, …, s″_{jL−1} 模 L 时每个剩余类恰好出现 j 次。则 N(j) ≤ M/L。

证：在偏移 0, L, …, M − L 各放 1 台机器人，按 g″ 以周期 M 循环（每台走 j 个相位循环，中间按 g″ − g 等待）。格 x 被 (b, i) 覆盖当且仅当 b ≡ x − s″_i (mod M)。b ∈ LZ_M 要求 s″_i ≡ x (mod L)，这样的 i 恰有 j 个，每个 i 对应唯一的 b。同一台机器人不会两次覆盖 x，因为 s″_i 在 [0, M) 中互不相同。所以每格恰好 j 台。∎

记 E_min(j) 为满足条件的最小总拉伸量。它只依赖 g mod L 这个循环序列，可以对"位置、当前余数、各余数已出现次数"做动态规划精确求出。于是
  **c(j) ≤ (E_min(j) − W(j))/L。**
单超周期的引理 6 是 j = 1、且部分和按等差排列的特例。[3,3,15] 在 K = 2 时的最优解正是这种结构：整数规划找到的 45 格双超周期模式为 [3, 3+1, 15, 3+1, 3, 15+1]，6 个部分和模 3 各出现两次。

**定理 6.4（L = 3 时 C1 成立）【机证】.** L = 3 时，对所有间隔序列和所有 K，c(K) ≤ 1，即 N(K) ∈ {⌈Kā⌉, ⌈Kā⌉ + 1}。

证：由定理 3，只需证 c(1) ≤ 1 和 c(2) ≤ 1。g mod 3 共有 11 个循环类，对每类和 j = 1、2 求 E_min，全部满足 (E_min − W)/3 ≤ 1。下表每行给出一组可行拉伸向量，可以手工核对。∎

**引理 6″（混合拉伸）【证明】.** 取 K 类机器人，共同周期 M = S + E（L | M）。第 i 类按某个总拉伸量为 E 的单超周期拉伸模式循环，偏移为 c_i + LZ_M（每类 M/L 台）。记 h_i 为第 i 类部分和模 L 的直方图。若对所有 r ∈ Z_L 有 Σ_i h_i(r − c_i) = K，则 N(K) ≤ K·M/L，即 c(K) ≤ (K·E − W(K))/L。

证：与引理 6′ 相同。第 i 类对格 x 的覆盖数为 h_i(x − c_i)，求和即得。∎

[3,3,2] 在 K = 2 时，整数规划的最优解就是这种结构：两类机器人分别在相位 0、相位 1 后多等 1 格，M = 9，两类的直方图 (1,2,0) 和 (2,1,0) 错开 2 后相加为 (2,2,2)。引理 6′ 在这里只能给出 c ≤ 1，混合构造给出 c = 0，这就是实际值。

**定理 6.5【机证】.** 对每个循环余数类和 k = K mod L，取引理 6′ 与 6″ 两个上界中较小的一个，记为 b(g mod L, k)，则 c(K) ≤ b。遍历全部余数类：
- **L = 2、3、4：所有类、所有 k 都有 b ≤ 1。所以猜想 C1 在 L ≤ 4 上成立：N(K) ∈ {⌈Kā⌉, ⌈Kā⌉ + 1}。**
- L = 5：629 个类中只有 (0,2,0,4,4) 在 k = 1 时 b = 2，其余全部 ≤ 1。对这个类直接算了 [10,2,10,14,4]、[5,2,5,9,9]、[5,7,5,4,4]，c 都是 1，所以 C1 在这里仍然成立，只是两类构造不够用。从整数规划的解里读出了第三类构造：模数取 P = 2L = 10，两类机器人的周期不同（30 和 40），偏移是 10Z 的陪集，两类部分和模 10 的集合互补（引理 6‴，证明同上）。它覆盖了该类 32 种模 10 提升中的 16 种，其余 16 种还需要更大的 P 或更多类。L = 4 时 (0,0,3,3)、K = 2 的三个具体序列也直接算过，c = 1。
- **L = 3 时，W(K) = 2 的所有情形都有 b = 0，所以猜想 C2 在 L ≤ 3 上也成立。**L = 4 有 8 个 (类, k) 组合没有覆盖（多数是 k = 1，此时混合构造不适用）；L = 5 有 318 个，其中确实存在 C2 的反例（见 2.7）。

**上界有多紧？** 用 628 组图谱数据核对：没有一组的实际 c 超过构造上界（这同时检查了代码的正确性），有 611 组（97%）恰好取等。也就是说，"拉伸 + 剩余均衡/混合"这一族显式构造，几乎总能达到真实最优。

### 2.7 猜想与证据

- **C1【猜想；L ≤ 4 已证（定理 6.5），L = 5 仅剩一类】c(K) ≤ 1。** 628 个 (g, K) 组合（90 个序列，含随机图谱 80 个和重点序列 11 个）中，c = 0 有 521 例，c = 1 有 107 例，没有 c ≥ 2。零余量时 c = 1 与"不可铺"一一对应（286/286）。
- **C2【L ≤ 3 已证；L = 5 被否定】正余量时，c = 1 ⇒ W = 1。** 图谱中 W = 1：109 例中 20 例 c = 1；W = 2、3、4：分别 114、40、5 例，全部 c = 0。直观解释是 W 为每个超周期可以挪用的等待总量（以班计），W ≥ 2 时调相位的自由度往往已经够了。
  - 定向搜索（L = 3、4、5，间隔 1–12，K ∈ {1,2}，160 个正余量组合）：W = 1 时 53 例中 18 例 c = 1；W = 2 时 75 例中 1 例 c = 1；W = 3、4 时 32 例全部 c = 0。
  - 唯一的 W = 2 反例是 [5,2,2,11,3]、K = 1（L = 5，S = 23，⌈ā⌉ = 5）。周期网络 ILP 扫到 P = 80 仍是 6；状态图精确判定（80730 个状态）确认 5 台不可行，6 台可行。**所以 C2 在 L = 5 不成立。**修正方向：阈值可能随 L 增长（例如 W ≥ ⌊L/2⌋ + 1 ⇒ c = 0），现有数据还不足以确定。
  - L = 3 时已证（定理 6.5）。证明过程中，引理 6′ 唯一没有覆盖的是 g ≡ (0,0,2) (mod 3) 且 K ≡ 2 (mod 3)。对这一类先直接算了 8 个序列（[3,3,2]、[3,6,5]、[6,3,8]、[3,3,5]、[6,6,2]、[3,9,2]、[9,3,5]、[3,3,11]）的 K = 2、5，全部 c = 0；然后从整数规划的解里读出了混合拉伸结构（引理 6″），补上了这一类。
- **C3【否定】"最优解总可以让所有机器人用同一个拉伸模式"。** 369 个可比例子中 11 例不成立，例如 [2,6,6] K = 1、[3,4,3,8] K = 1。
- 固定模式与允许等待的差：随机图谱 496 组中差 0/1/2 分别为 373/105/18 例；[3,6,3,6,9] 在 K = 1 时为 9 对 6，差 3。等待在稳态下确实有用，"稳态 = 循环覆盖"不成立。
- 正余量、c = 1 的情形原来只在周期 P ≤ 2S 至 4S 内做了穷尽整数规划，这不是对所有周期的证明。本轮补了**状态图精确判定**（`statecycle.py`）：状态取 N 台机器人的多重集 {(下一相位, 距可用剩余格数)}，反复删去没有存活后继的状态，最后非空当且仅当存在无穷（因而周期）排班。它与周期上限无关。先在 [3,10]、[2,4]、[3,3,15] 的已知值上校验无误，再批量处理图谱和定向搜索里全部"正余量、K = 1、c = 1"的实例：状态数不超过 150 万的 13 例**全部严格确认** c = 1（12 例 W = 1，1 例 W = 2，即 C2 反例）。例如 [2,6,3]、[6,5,3]、[3,6,8]、[4,6,5,4]、[3,7,5,4]、[5,6,9]、[3,10,10,3,3]。另有 8 例状态过多而跳过。状态数是 C(S+N−1, N)，所以这个方法只适用于小实例。

### 2.8 复杂度现状

- 相位提升的周期网络的 LP 松弛值恒为 Kā（流体均匀解），**不是整数的**，所以 Orlin 1982 式的"最小流 = 精确解"不能直接推广到 L ≥ 2。网络 LP 只给出流体值。
- L ≤ 4 时（定理 6.5），精确求 N(K) 等价于判定 c(K) ∈ {0, 1}。构造上界 b 只依赖 g mod L 和 K mod L，计算量与 S、K 的大小无关；b = 0 时直接得到精确值。
- b = 1 时，零余量的情形就是 K 重铺砌判定：K = 1 且 L 至多含两个不同素因子时，在 S 的多项式时间内可判定（推论 4.1）；一般 K 的复杂度未知。
- b = 1 且正余量时，小实例可以用状态图精确判定（指数级，但与周期无关），没有理论上的障碍定理。**这是现在最缺的一块**：需要一个对正余量也成立的"近铺砌"障碍定理，作为定理 4 的推广。

## 3. 全新同相位启动

### 3.1 定义

N_fr(K) 是全新启动的最少台数。由于 N_fr(K₁+K₂) ≤ N_fr(K₁) + N_fr(K₂)，由 Fekete 引理，α_fresh = lim N_fr(K)/K = inf_K N_fr(K)/K 存在。任何全新无穷排班都包含一个稳态周期段（状态有限），所以 N_fr(K) ≥ N(K)。

### 3.2 槽权重引理（LP 对偶的组合形式）【证明】

**引理 7.** 设 y: [0, H) → R。若任何一台从相位 0 出发的单机轨迹（可以等待、可以不上岗）在它的上岗格上收集的 Σy ≤ 1，则对所有 K，N_fr(K) ≥ K·Σ_t y_t。

证：每格恰好 K 台上岗，所有机器人收集的总量 = K·Σy。每台 ≤ 1，所以 ≤ N。∎

最优的这类 y 就是时间展开 LP 的对偶解，记其值为 α_H。α_H 关于 H 单调不减，并且 α_fresh ≥ sup_H α_H。用 HiGHS 解对偶，把解有理化后用分数精确核对可行性，得到下表。【机证】

| g | ā | α_H（仅等待） | α_H（允许提前大修） |

### 3.3 显式反例族：启动代价线性增长【证明】

**定理 8.** g = [1, 2k]（S = 2k + 1）。定义权重（单位 1/S）：
- w(t) = ⌊t/2⌋ + 1，0 ≤ t < 2k；
- w(2k) = k + 1；
- w(t) = ⌈(4k − t)/2⌉，2k < t < 4k；
- 其余为 0。

则任何单机轨迹收集的 Σw ≤ S，且 Σ_t w(t) = 2k² + 2k + 1。因此
  N_fr(K) ≥ K(S² + 1)/(2S)，N_fr(K) − N(K) ≥ K/(2S) − 1/2。

证：机器人依次在相位 0、1、0、1 上岗于 t₁ < t₂ < t₃ < t₄，约束为 t₂ ≥ t₁ + 1、t₃ ≥ t₂ + 2k、t₄ ≥ t₃ + 1，而 t ≥ 4k 处权重为 0。第五次上岗已在 4k 之后，不计。
- 只有两次落在支撑内：w 单峰，峰在 2k，所以 w(t₁) + w(t₂) ≤ w(2k−1) + w(2k) = k + (k+1) = S。
- 三次或四次（t₂ < 2k）：利用 ⌊(t−1)/2⌋ + ⌊t/2⌋ = t − 1，得 w(t₁) + w(t₂) ≤ t₂ + 1。利用 ⌈x/2⌉ + ⌈(x−1)/2⌉ = x，得 w(t₃) + w(t₄) ≤ 4k − t₃ ≤ 2k − t₂。合计 ≤ 2k + 1 = S。只有三次时更小。
- 权重和：上升段 2(1 + … + k) = k(k+1)，峰 k+1，下降段 k + 2(1 + … + (k−1)) = k²，合计 2k² + 2k + 1。
- 由引理 7 得下界。又由定理 5（a = 1 是奇数），N(K) = ⌈KS/2⌉ ≤ KS/2 + 1/2。∎

脚本对 k = 1…40 用动态规划逐一核对了"单机最大收集量 ≤ S"。LP 值与 (S² + 1)/(2S) 对 G ≤ 20 全部相等，所以这个下界在流体层面是紧的。

> **含义**：全新机队同时上线，额外的台数不是一次性的常数，而是 ∝ K。原因是所有机器人同相位出发，第一轮大修必然扎堆，必须用"多买机器人"来承担错峰期间的闲置。稳态的 O(1) 精确常数和全新启动的线性代价是两种不同性质的现象。

### 3.4 零启动代价的刻画

**定理 9（充分性）【证明】.** 若 A(z) 整除 1 + z + … + z^{S−1}，且商 B(z) 的系数非负，记 D 为 B 系数的公分母，则 D | K 时 N_fr(K) = Kā，所以 α_fresh = ā。

证：让 K·B(b) 台机器人在时刻 b 进入（此前在相位 0 等待），此后不再等待。deg(AB) < S，所以 b + a ≤ S − 1，不会越界。任取 x = r + jS（0 ≤ r < S），机器人 b 覆盖 x 当且仅当存在 a 使 b + a ≡ x (mod S) 且 b + a ≤ x，也就是 b + a = r。覆盖数为 K·Σ_a B(r − a) = K。∎

- 例子：[c, …, c, G] 且 Lc | S 时，B = {0, …, c−1} ⊕ Lc·{0, …, S/(Lc) − 1}。
- 整数且 B 为集合时，A ⊕ B = {0, …, S−1} 是经典的"区间互补对"。de Bruijn（1956）证明它们都来自混合进制数系（Krasner–Ranulac 1937 也有相关结论），可以完全枚举。

**猜想 C4【数值】：α_fresh = ā ⇔ 定理 9 的条件成立。** 478 个序列（L = 2、3、4 的随机抽样，加上 [c, …, c, G] 族）全部一致。其中 25 例满足条件，都是 [1,3,1,3]、[5,5,5]、[2,2,8]、[1,1,1,9] 这类"混合进制"结构。也就是说，**零启动代价是罕见的；一般间隔序列在全新启动时都要付线性代价。**

### 3.5 L = 2 的流体数据【数值】

g = [a, G]，r = S mod 2a，m = min(r, 2a − r)，q = ⌊S/(2a)⌋，e = α_fresh − S/2。
- e = 0 ⇔ r = 0（a ≤ 7、G ≤ 10a + 1，共 266 例；充分性见定理 9）。
- r ≥ a − 2 时 e = m/(2(2q + 1))，r = a 时化为 a²/(2S)。a = 1 时即定理 8。
- r 较小时偏离这个式子（例如 a = 5、r = 2），a = 7 时出现非整数拟合参数。说明 LP 值是分段的，一般闭式还没有找到。

### 3.6 整数值与"取整即精确"

用两种界夹定精确值：下界取 max(⌈α_H·K⌉, N(K))；上界用"时间展开到 T + P + g_max，并强制末段按周期 P 重复"构造可以无限延拓的排班。该构造是严格上界，证明见 `fresh_tail.py` 头部注释。
- 【机证】10 个重点序列在 K = 1…10（共 100 组）上，上下界全部相等，且等于 ⌈α_H·K⌉。例如 [4,4,5] 是 5, 10, 15, 19, 24, 29, 33, 38, 43, 48（就是 ⌈33K/7⌉）；[4,4,5,4,9] 是 ⌈47K/8⌉。由于 α_fresh = inf_K N_fr(K)/K，只要某个 K 使 N_fr(K) = α_H·K，就严格推出 α_fresh = α_H。例如 [4,4,5] 的 N_fr(7) = 33，所以 α_fresh = 33/7 恰好成立。
- 另取 30 个序列（10 个指定、20 个随机，L = 2–4），在 K = 1…6 上比较（共 180 组）：173 组的上界构造等于下界 max(⌈α_H K⌉, N(K))。其余 7 组都恰好多 1，并且已用有限时域 ILP 的下界确认是真实差距，不是上界构造的搜索限制：
  - [1,2,6]、K = 6：α = 231/73（H 从 2S 到 12S 不变），⌈6α⌉ = 19，稳态 N = 18，而有限时域 ILP 在 H = 4S 时已给出下界 20；
  - [3,3,4,8]、K = 1、2、5：α = 5（N_fr(3) = 15 说明 5 是精确值），实际为 6、11、26；
  - [2,4,14]、K = 1、2、4：α = 7，实际为 8、15、29。
- 【否定】"整数取整总是精确"不成立。
- **修正猜想 C5：N_fr(K) ∈ {⌈α_fresh K⌉, ⌈α_fresh K⌉ + 1}。**在全部 280 组上成立。其中相等的 273 组，下界都是严格对偶证书给出的 ⌈α_H K⌉（不依赖稳态数值），所以是严格夹定；多 1 的 7 组由有限时域 ILP 的下界严格确认。
- 允许提前大修时，同样 30 个序列、K = 1…6 共 180 组：上界构造全部等于 max(⌈α_R K⌉, N_R(K))。其中 156 组由严格对偶证书夹定；14 组的下界取自稳态值（零余量铺砌缺陷）；另有 2 个序列（[3,3,4,8]、[3,6,4,8]）的对偶解有理化失败，只能用近似 LP 值。提前大修时，**整数取整在全部样本上都是精确的**。
- 暂态长度：流体值在 H = 2S 到 3S 处已经达到。整数最优多数在 H ≤ 2S 时稳定，[1,2,6] 在 K = 6 时需要 4S。"有限期最优 = 无限期最优"的分界 H₀ 与超周期同阶，符合 turnpike 的直觉；但到达的极限不是稳态最优，而是一个更高的流体值。

## 5. 随机维修时长：√K 定律【数值】

**设定**：小间隔确定，大修间隔在 [G₀ − δ, G₀ + δ] 上均匀取整。服务水平为长时域缺岗格比例 ≤ 10⁻³（预热 3000 格后统计），二分求最少台数。派工策略 PB（相位平衡）：每格按各相位累计派工的缺额分配 K 个名额，同相位内先到先派。确定性时它对 [3,10]、[4,4,5] 恰好达到 ⌈Kā⌉。FIFO 策略在 [4,4,5,4,9] 上确定性时也会线性超额，所以不用 FIFO 做结论。

表中每格是"超额台数 N_ε − Kā（超额/√K）"。

| g | δ | K = 1 | 4 | 16 | 32 | 64 | 128 |
|---|---|---|---|---|---|---|---|
| [3,10] | 0 | 0.5 | 0 | 0 | 0 | 0 | 0 |
| [3,10] | 2 | 2.5 | 4（2.0） | 8（2.0） | 12（2.12） | 16（2.0） | 23（2.03） |
| [3,10] | 4 | 2.5 | 6（3.0） | 12（3.0） | 16（2.83） | 24（3.0） | 37（3.27） |
| [3,10] | 6 | 3.5 | 6（3.0） | 13（3.25） | 18（3.18） | 27（3.38） | 36（3.18） |

| [2,2,5] | 1 | 1 | 2（1.0） | 5（1.25） | 7（1.24） | 11（1.38） | 17（1.5） |
| [2,2,5] | 2 | 1 | 4（2.0） | 7（1.75） | 10（1.77） | 14（1.75） | 18（1.59） |

**读法**：
- 确定性时超额 = 取整的小数部分，也就是 N = ⌈Kā⌉。有随机性以后，[3,10] 和 [2,2,5] 的超额/√K 在 K 从 4 到 128 上稳定在一个常数附近，常数随 δ 增大。上一轮 FIFO 的数据给出同样的规律：δ = 3 时比值约 2.9，δ = 6 时约 3.9。
- [4,4,5] 在 K = 64、128 时比值明显上升，复核确认是时域太短造成的估计噪声：K = 128 时只用了 12000 格，10⁻³ 的缺岗率只对应十几个缺岗格。改用 T = 60000、3 个随机种子以后，δ = 2 时 K = 16、32、64、128 的比值为 1.67、1.65、1.58–1.83、1.71，回到常数。
- 所以在 [3,10]、[2,2,5]、[4,4,5] 三个序列上，随机大修下的超额都 ∝ √K。这与 RMAB 渐近理论中"非退化时 O(1)、一般 O(√N)"的分界一致：**确定性周期臂的 O(1) 精确常数来自零方差，√K 来自随机性本身。**这是可以写成命题的桥接论断。严格化需要：(i) 一个具体策略的 √K 上界（安全库存 + 中心极限）；(ii) 任何策略的 Ω(√K) 下界（大修数量的波动不可避免）。两者都不难，可以作为下一步。

## 6. 分组损失（多点共享 vs 分组）【证明 + 数值】

把 K 个点分成 m 组，各组独立排班。分组损失 = Σ N(K_i) − N(ΣK_i) ≤ Σ(⌈K_i ā⌉ + c(K_i)) − ⌈Kā⌉ ≤ (m − 1) + Σ c(K_i)。
- K = 12 时的最大损失（括号内为界）：[3,10] 在 m = 2、3、4 时为 1(1)、1(2)、2(3)；[3,6,3,6,9] 为 1(1)、2(2)、3(3)，界取等。
- 专点分组（m = K，每组一个点）的损失 = K·N(1) − N(K)，随 K 线性增长，斜率为 N(1) − ā。[4,6,5,4] 在 K = 12 时达到 15 台。
- 结论：**共享是线性收益，分组损失有 O(m) 的精确上界。**这接到《多地值班问题》文档：多地异构需求时，"哪些点合并成一组"会变成一个组合优化问题，代价函数就是本节的 N(·)。

## 7. 与文献的关系、新颖性边界

**已知、直接用到的结果**
- 固定模式循环覆盖：Bartholdi, Orlin, Ratliff, OR 28(5), 1980，给出 N ≤ S⌈K/L⌉ 这一类初等界。
- 常周期 pinwheel 覆盖、密度 1 ⇔ 不交覆盖系：Kawamura & Soejima。定理 4 是它在"单一带模式 agent、K 重需求、允许等待"情形下的推广，结论变成平移铺砌。
- 平移铺砌：Coven & Meyerowitz（J. Algebra 212, 1999，T1/T2 判据）；Kolountzakis & Matolcsi（arXiv 0810.4338，Z_N 局部判据及多项式算法）；Steinberger（NYJM 11, 2005，多重铺砌与水平半群）；de Bruijn（1956）区间互补对与混合进制。
- 大规模 restless bandit：Hong 等；Brown & Zhang；Gast, Gaujal, Yan。这些结果用于第 5 节的对照，以及"非周期性假设"这一桥接点。

**据我们检索未见、可以作为贡献的部分**（投稿前仍需在周期调度文献里专门核查"零余量 ⇔ 铺砌"是否有人写过）
1. 最少机队与平移铺砌的等价（定理 4），以及由此带来的分圆判据、水平半群现象。
2. L = 2 闭式（定理 5）；只依赖 L 的超额上界（推论 6.1）；等差族的精确值。
3. 最终周期性与 c* 的单调结构（定理 3）；显式拉伸构造族（引理 6′、6″、6‴）及其推出的 C1 在 L ≤ 4、C2 在 L ≤ 3 的证明；C2 在 L = 5 的严格反例；状态图精确判定方法。
4. 全新启动：线性代价定理（定理 8）、槽权重证书方法、区间铺砌刻画（定理 9 + 猜想 C4），以及"提前大修消除启动代价"的机证结果。这一块实践意义最直接，也最反直觉。
5. 随机维修的 √K 定律（目前是数值结果）。

**需要如实说明的边界**
- 推论 4.1 的判据本身是 Kolountzakis–Matolcsi 的定理，我们的贡献是归约。
- 正余量的上界构造（拉伸）比较初等，C1、C2 才是难点。
- 全新启动的整数值结论目前只到"机证 + 猜想"，[1,2,6] 的反例说明它的整数结构并不平凡。

1. **正余量的下界技术**（主线 A 的最大缺口）：把定理 4 的"零浪费 ⇒ 铺砌"推广为"浪费恰好为 W ⇒ 近铺砌"。全体机器人在一个公共周期 Π 内的总等待恰好是 Π·W/L，需要证明这么少的等待不足以修补某些余数结构。先拿状态图已严格确认的最小例子手工推：[4,6,5,4] K = 1（W = 1）、[5,2,2,11,3] K = 1（W = 2）。
