# 无限期下界与周期解验证（2026-10-14）

| 文件 | 作用 |
|---|---|
| `lb.py` | 单台机器人的维修超周期；速率下界（无限期）与贪心精确的有限期下界 |
| `lb_mixed.py` | 允许混用机器人型号的连续松弛下界（较弱） |
| `verify3.py` | 同型 N 台：在有限状态图上找"前缀+周期"，再按此计划构造编码 x，用原始 `evaluate()` 复核。用法 `python verify3.py group`（或 `orig`） |
| `finite_check.py` | 有限时域内同型 N 台能否覆盖全部班次（精确 DFS） |
| `verify2.py` | 旧版验证（只支持原工具解码），保留 |

## 结论（只用 0 型机器人 + 6 件工具）

| 实例 | 速率下界 | 精确最少（有限期与无限期相同） | 原工具解码能否表示 | 分组工具解码能否表示 | MOEA 实际找到（10 种子最好/均值，分组解码） |
|---|---|---|---|---|---|
| L1-720 | 7+6 | **13** | 能 | 能 | 13 / 13.1 |
| L1-1440 | 7+6 | **13** | 能 | 能 | 13 / 13.8 |
| L2-720 | 5+6 | **11** | 不能 | 能（H=20000 也可行） | 12 / 12.0 |
| L3-720 | 6+6 | **12** | 不能 | 能（H=20000 也可行） | 14 / 14.1 |
| L3-1440 | 6+6 | **12** | 不能 | 能 | 15 / 15.9 |

- "精确最少"指只用同一型号时的最优值：N-1 台在有限时域内即无法覆盖（`finite_check.py`），N 台存在可无限重复的周期。混用型号的全局最优尚未证明（混型下界只有 10–11）。
- 修正解码器后最优解可以被编码表示，但 MOEA 在全展开编码上仍找不到它：这是"编码长度随时域增长导致搜索困难"的直接证据，也是改用"前缀+周期"编码的依据。
- 找环得到的周期解只保证 f1 最优，f2 未优化（如 L3 在 H=20000 时 f2=106）。在周期集合里挑均衡度好的周期，是下一步周期编码 MOEA 的任务。
