# 混型（不同值岗时长）+ 工具：最少资源数的精确求解（2026-10-14）

`mixed_exact.py`：事件时间状态的精确搜索（时间单位 0.1h，状态 = 各机器人(型号, 还需等待, 各级维修剩余) + 各工具(型号, 相对可用时刻)，同类合并），规则与 `roster_sim.evaluate` 一致；工具组合按真实问题枚举（相当于 `tool_dec="group"`）。
`search_min.py`：按总资源数递增枚举全部配置（各型机器人数 × 各型工具数），判定无限期（找环）/ 有限期 H（深搜 + 失败记忆）可行。
剪枝：无限期用速率下界 Σ n_r ρ_r ≥ 1；工具数 ≥ 2×每班工具数（相邻两班工具必不相同）。有限期不用速率剪枝。
`resolve.py`：对节点上限内未决的配置加大上限重算。

用法：`python search_min.py L3-720 9 13 100000 fin|inf|both`

## 结果（混型也计入，全部是证明过的最优）

| 实例 | 有限期最少 | 无限期最少 | 最优配置示例（机器人 0/1/2 型；工具 0–3 型） | MOEA 最好 |

- "最少 = k" 的含义：总资源 < k 的所有配置都被证明不可行（L1 在 12 时有 2 个配置首轮未决，加大上限后均证明不可行）。
- 混型不比同型更省；之前的混型连续下界 10–11 只是下界太松。
- 同型最优解已在原 `evaluate()` 中复核（见 `无限期下界/`）；混型最优配置 (3,0,2)、(5,0,1) 还没有回放到原 `evaluate()` 复核。
- 每个实例 1–4 分钟（Python）。
