# 多域轮转排班（multi-domain rotation rostering）

多站点、多机型、带维修超周期的长周期机器人轮转排班：下界（轮转周期松弛）+ 进化算法。

上一篇论文（规则偏离解码，RDD）在仓库 `whc-229/decoding-research`，本仓库不改动它。

## 先读
1. `研究笔记/00_项目起点.md`：老师的意见、问题范围、已有结果、待定事项。
2. `CLAUDE.md`：工作约定（服务器上的 Claude Code 也读这一份）。
3. `TASKS.md`：交给服务器的任务队列。
