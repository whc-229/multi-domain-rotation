取代 `02_解码方案与实验思路.md` 的 §4–§6（三层对照、8 种解码、5 种时域模型）。原则：

## 1. 主线与框架（10-31 修订：时间界）
超长排班如果整段编码，染色体长度会随时域增长，没法做。所以要先找一个**时间界**：只需要在多长的一段里优化。

- 自然周期太长（几年到几十年），编码一个周期不可行；
- 难点只在启动期：全新机队上线后，第一轮大修扎堆。

从轮转周期出发构造松弛，同一个松弛给出四样东西：
1. 资源数下界；
2. 时间界 H₀：松弛在 H₀ 处收敛；
3. 启动期的错峰计划；
4. 稳态规则。

进化算法只编码启动窗口 W₀ 内的偏离，染色体长度与总时域无关；窗口之后按规则运行，判环证书保证永远可行。

框架由五个部件组成（加一个候选部件 C6），消融按部件逐个拆：

| 部件 | 作用 |
|---|---|
| C1 松弛规则 | 按 LP 的机型配比和值岗流派工 |
| C2 启动期错峰计划 | 按 LP 在启动窗口内安排提前大修 |
| C3 启动窗口偏离编码 | 基因只编码启动窗口 W₀ 内的少数偏离，其余决策按规则；W₀ 由时间界确定 |
| C4 无限时域适应度 | 判环证书，判不出时用长时域复核，保证解永远可行 |
| C5 定台数下降评价 | 固定台数只数缺岗，只对候选做完整判定，让方法能跑大实例 |
| C6 对偶引导偏离（候选，看 T16） | 偏离优先落在 LP 对偶价格高的决策上，也就是大修扎堆的时段 |

## 2. 实验

### 实验 1：松弛（对应论文的下界一节）
- 下界对不对：单站带工具时，下界等于已知最优（L1/L2/L3：13/11/12）；
- 启动代价：按站数列出 LP_fr − R_rate_g 和 LP_fr^Rw − R_rate_g；
- 一张表、一张图。

### 实验 1′：时间界（T17、T18）
- LP 下界随时域 H 的收敛，得到 H₀；
- 对偶价格在时间上的分布：价格集中在第一轮大修扎堆的时段；
- 自然周期长度：说明编码一个周期不可行；
- RDD 启动窗口 W 的扫描，得到 W₀，并与 H₀ 对照。

### 实验 2：与其他方法对比（主实验）
在测试实例上做，站数 2–20，K1 和 K12 两个族。对手都用同一个仿真器、同一套长期可行判定、同样的预算（评价次数或墙钟时间，待定）。

| 对手 | 代表什么 | 来源 |
|---|---|---|
| FIFO、PB（相位平衡） | 经典手写派工规则 | 试点 |
| ES-DW | 逐实例用进化策略调派工权重（启发式空间搜索） | 试点的 ES |
| GPHH | 遗传规划超启发式进化派工规则，在训练实例上训练，在测试实例上直接用。这是 TEVC 上进化派工规则的主流做法 | 试点有 GP 实现；文献：Branke 等 2016、Huang 等 TEVC 2025 |
| RK-EA、D5-EA | 逐决策编码：原排班软件的随机键；上一篇最好的逐决策解码 dec5 | 原软件、RDD 论文 |
| RDD-hand | 上一篇的 RDD，默认规则是手写的 | RDD 论文 |
| RH-MIP | 滚动时域整数规划：按窗口求时间展开的 MIP，固定前段，向后滚动。人员排班里常用的做法 | 例如 Racette 等 2025 的 crew rostering windowing |

- 指标：资源数离可验证下界的差距、长期可行率、用时。
- 统计：同实例配对的 Wilcoxon 符号秩检验加 Holm 校正；所有方法的 Friedman 平均秩。

### 实验 3：消融（证明框架有用）

| 变体 | 去掉什么 | 要说明什么 |
|---|---|---|
| w/o C1 | 默认规则换成手写规则 PB | 规则来自松弛比手写好 |
| w/o C2 | 不要启动期错峰计划 | 错峰计划能省资源 |
| w/o C3 | 只用松弛规则，不搜偏离 | 搜索有用 |
| w/o C4 | 适应度只看 720 h | 有限时域会得出长期不可行的解（这里讲长周期问题） |
| w/o C5 | 每次评价都完整定台数 | 下降评价让大实例可解，资源数不变差 |
| w/o C6 | 偏离位置均匀分布 | 对偶价格能指出该在哪里偏离（T16 有效时才放进来） |

### 实验 4：参数与规模
- 偏离率 ρ、启动窗口长度：在训练实例上扫描，报告敏感性；
- 用时随站数的变化。

## 3. 删掉的
- 建模层的 5 种时域模型对比：
  - 720 h 并入消融 w/o C4；
  - 滚动时域改为对手 RH-MIP；
  - 拉长时域、固定周期不做。
- 周期偏离槽、周期结构编码、换优化器、算法适配逐项消融：都不做。
- LLM、RL：不做。我们不训练神经网络，老师说的"训练网络要和 PPO 比"不适用。
