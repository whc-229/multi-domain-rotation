# 08 配图提示词（2026-11-04）

## 分工
| 图 | 位置 | 怎么画 |
|---|---|---|
| 图 1 场景示意 | III 问题 | 生图模型（提示词 A） |
| 图 2 核心思路 | I 引言 | 生图模型（提示词 B） |
| 图 3 方法框架 | V 方法 | 生图模型（提示词 C） |
| 接入例子（fig:enter） | IV 时间界 | 代码，已画：`code/figs/fig_enter.py` → `manuscript/figures/fig_enter.pdf` |
| 实验图（下界收敛、窗口长度、对比、消融） | VI 实验 | 代码，等第五批结果 |

## 顶刊配图的共同要求（每条提示词都已写进去）
- 平面矢量风格，白底；不要 3D、阴影、渐变、照片质感、卡通吉祥物。
- 颜色少而固定，全文统一：深蓝 #1F4E79（阶段 0 / 主要元素），浅蓝 #9DC3E6（其他阶段），橙色 #D9822B（启动期、提前大修、强调），灰色（等待、辅助线）。与 fig:enter 一致。
- 细线（0.5–1 pt），无衬线字体，最终尺寸下字号 8–9 pt；文字只用短标签。
- 尺寸：单栏 88 mm（3.5 in）宽，双栏 181 mm（7.16 in）宽。
- 生图模型常把文字和公式画错：先按提示词出图；文字如有错，让模型出"无文字版"，再在 PPT / Inkscape / draw.io 里按标签表补字（公式标签用 LaTeX 渲染后贴上）。
- 最好导出 SVG 或 PDF；只有位图时至少 600 dpi。

```
A clean, flat, vector-style scientific schematic for an IEEE Transactions journal paper, white background, no 3D, no shadows, no gradients, no photorealism. Thin dark-gray outlines (about 0.75 pt). Limited palette: dark blue #1F4E79, light blue #9DC3E6, orange #D9822B, grays. Sans-serif labels, short and legible. Wide layout, aspect ratio 3:1.

Left: one depot drawn as a simple rectangular building outline labeled "Depot". Inside it, two small bays labeled "Maintenance" and "Overhaul".
Right: three sites drawn as rounded rectangles labeled "Site 1", "Site 2", "Site 3", placed at increasing distances from the depot. Each site contains a few small square slots (posts); site 1 has 2 posts, site 2 has 3 posts, site 3 has 2 posts. Every post is occupied by a small robot icon.
Robots: simple geometric icons, two robot types distinguished by shape (type A: circle body, type B: hexagon body), filled dark blue. Each robot on duty carries a tiny tool module (small light-blue square attached to its side).
Between the depot and each site, thin arrows in both directions; a few robots are shown traveling on the arrows. Label one arrow "travel time".
Bottom-left inset, framed with a thin gray border, titled "Maintenance cycle of a robot": a horizontal chain of boxes "Duty" → "Short maint." → "Duty" → "Short maint." → "Duty" → "Overhaul", with a curved arrow from "Overhaul" back to the first "Duty". The "Overhaul" box is orange.
Bottom-right small text box: "New fleet: all robots start at slot 0, right after an overhaul".
Balanced whitespace, no decorative elements, no logos.
```

补字标签：Depot、Maintenance、Overhaul、Site 1–3、travel time、Maintenance cycle of a robot、Duty、Short maint.、New fleet: all robots start at slot 0, right after an overhaul。

## 提示词 C：方法框架（图 3，双栏，宽高比约 3:1）

```

Rounded rectangles with thin dark-gray outlines, arrows with small solid heads. Palette: dark blue #1F4E79 for main boxes (white text), light blue #9DC3E6 for data boxes (dark text), orange #D9822B for anything about the start-up window, light gray for the final check. Sans-serif labels. Aspect ratio 3:1. Flow from left to right in three columns.

Column 1, titled "Relaxation": a light-blue data box "Instance" with an arrow to a dark-blue box "Rate relaxation (LP)". From it, two arrows to two light-blue boxes stacked: "Duty flows" and "Early-overhaul plan (start-up window)" (the second has an orange border).

Column 2, titled "Encoding and decoding": a dark-blue box "Rotation rule" receiving both arrows from column 1. Above it, an orange box "Genotype: a few deviation slots" drawn as a short strip of 4 cells, each cell showing two small sub-cells labeled "position" and "value". An arrow from the genotype to a dark-blue box "Decoder" that also receives an arrow from "Rotation rule". Inside or beside the decoder, a small horizontal timeline: an orange segment "window: rule + deviations" followed by a dark-blue segment "after the window: rule only".

Column 3, titled "Search": a dark-blue box "Evolutionary search" with a circular arrow (loop) back to the genotype in column 2. Below it, a dark-blue box "Fleet-descent evaluation" with the subtitle "fixed fleet, count shortages; remove a robot or tool while feasible". At the far right, a small light-gray box "Long-run check" with an arrow to the output box "Fleet and schedule".

Keep generous spacing and aligned boxes; all arrows orthogonal; no decorative elements.
```

补字标签：Relaxation、Instance、Rate relaxation (LP)、Duty flows、Early-overhaul plan (start-up window)、Encoding and decoding、Rotation rule、Genotype: a few deviation slots、position、value、Decoder、window: rule + deviations、after the window: rule only、Search、Evolutionary search、Fleet-descent evaluation、fixed fleet, count shortages; remove a robot or tool while feasible、Long-run check、Fleet and schedule。

注意：图 3 依第五批的最终配置定稿；第五批若改了组件（例如去掉互换算子），框图跟着改。
