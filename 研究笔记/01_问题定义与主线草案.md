# 01 问题定义与主线草案（2026-10-27）

> 状态：多域含义和主线已定（见 §6）；场景、规模和目标待实验后再定。

## 1. 已有结果：哪些站得住，哪些只是试点

### 1.1 站得住
理论部分（全部建立在"单一机型、K 个同质点、以班次为格"的抽象模型上）：
- 速率下界 N ≥ ⌈Kā⌉【证明】。
- 稳态：
  - 最终周期性（定理 3）；
  - 零余量 ⇔ K 重平移铺砌（定理 4）；
  - L = 2 的闭式（定理 5）；
  - 离下界的差只依赖 L（推论 6.1）；
  - L ≤ 4 时差 ∈ {0, 1}（定理 6.5，机证）。
- 共享与分组：分组损失 ≤ (m−1) + Σc(K_i)；专点分组的损失随 K 线性增长【证明】。
- 全新启动：
  - 启动代价可以随 K 线性增长（定理 8，显式族 [1, 2k]）；
  - 全新启动 LP 的对偶就是"槽权重"（引理 7）；
  - 25 个序列有精确有理证书。
- 提前大修：10 个序列在 K = 1…10 上被上下界夹定（机证），其中 6 个序列的线性代价消失。

方法与实验：
- 无限期证书：确定性、状态有限的派工最终一定进入周期，环内无缺岗就证明永远可行。依据有出处（Grolleau 等），实现经过精确重放核对（305/305）。可以当可靠组件用。
- 全新启动 LP 下界：单站带工具的 L1/L2/L3 为 13/11/12，等于已知最优。
- 有限时域评估的漏洞：按 720 h 优化时，2–10 站一半以上的解长期不可行；同样的预算下，严格证书 84/84 次长期有效。
- 单型多岗位 L1 系列的 9 个实例：LP 计划 + 进化派工全部达到"允许提前大修"时的精确最优。

### 1.2 只是试点
- 多站上的方法对比，大多只有 1 个或 3–5 个种子，每个规模 2–4 个实例；进化预算很小（(4+12)-ES，10 代）。
- 多站的 LP 计划 + 进化派工：
  - 2–4 站平均少 0.58 个资源（36 对），有的实例反而变差；
  - 6 站只跑完 s1 和 s2 的 1 个种子；8 站 s2、10 站的下界没算完。
- 剩下 5–16% 的差距，是下界松还是算法差，没有分清。真实最优只在 2 站 s1、s2 上夹到 26–28。
- 周期结构编码：只算机器人、每个实例只跑 1 次，10 站 s2 落后 2 台。
- GP 不如线性规则、策略迁移效果时好时坏、√K 规律：都只是数值观察。
- **理论全部是单机型的。**多机型、多站点、带路程偏移和工具时，没有对应的定理，多站的下界目前全靠 LP。

### 1.3 需要统一的口径（新发现）
- 早期试点用了 1000 格预热：机器人全新上线，但前 1000 格的缺岗不计。涉及的结果有：`试点说明.md` §3 的只算机器人表、`证书适应度试点说明.md` §4″ 的结构编码对比表、`scale_tools.py`。
- 这种口径既不是稳态（稳态允许任意初相位），也不是全新启动。证书和启动代价两份笔记都用 warm = 0。
- 所以"6 站 38 台对下界 36"这类数字，不能和后面带工具的全新启动数字直接比较。
- 正式实验只用两种口径：全新启动（warm = 0），或稳态（初相位自由，只作参照）。

## 2. 问题定义草案：多域轮转排班（Multi-Domain Rotation Rostering，MDRR）

"域"暂定为值班站点（见第 6 节第 1 条）。

### 2.1 数据
- 时间网格：t ∈ Z≥0，格长 u = 2 h。
- 机型 k ∈ 𝒦：
  - 值岗 d_k 格；
  - 维修超周期有 L_k 个相位，相位 i 的占用为 o_{k,i} 小时（含准备、装工具、去程、值岗、收尾、返程、卸载、充电或维修）；
  - 适配工具型 C_k，每班需 q_k 把；
  - 单价 c_k。
- 站点 s ∈ 𝒮：允许机型 E_s ⊆ 𝒦，额外单程路程 δ_s，需求 K_s（每格在岗台数）。
- 工具型 j ∈ 𝒥：安装、卸载、保养时长。

### 2.2 决策
- 机队规模：每型机器人台数 N_k，每型工具把数 M_j。
- 每台机器人的无限动作序列：每一步是"值一班"（站点 s、值岗开始 D、所带工具）、"等待"或"提前大修"（如果允许）。
- 等价说法：在本型的轮转图上走一条无穷路径（见 §3）。

### 2.3 约束
1. 覆盖：站 s 从开班时刻 t_s⁰ 起，每格恰好有 K_s 台允许机型的机器人在岗。班与班首尾相接，不同机型的班长可以不同。
2. 轮转：k 型机器人在相位 i、虚拟时刻 v 去站 s 值岗时，
   - 值岗开始 D = v + ⌈δ_s/u⌉，覆盖 [D, D + d_k)；
   - 下次就绪 v′ = D + ⌈(o_{k,i} + δ_s)/u⌉，相位变为 i+1 (mod L_k)；
   - 可以等待任意格。
3. 提前大修（可选）：在相位 i ≠ L_k − 1 值完一班后，可以按相位 L_k − 1 的占用直接大修，回到相位 0。
4. 工具：每班带 q_k 把 C_k 中的工具，工具在 [D − pre, D + d_k + post_j) 内被占用；一把工具同一时刻只能跟一班。
5. 初始条件：
   - 全新启动：t = 0 时所有机器人都在相位 0、就绪；
   - 稳态（参照）：初相位和就绪时刻自由。
6. 时域：无限。可行指对所有 t ≥ t_s⁰，约束 1–4 都满足。

### 2.4 目标
- 主目标：f1 = Σ_k c_k N_k + Σ_j M_j。c_k = 1 时就是原问题的"机器人数 + 工具数"。
- 候选次目标：提前大修次数、均衡度（原 f2）、随机大修时长下的缺岗率。

### 2.5 继承与新增
| 要素 | 来源 |
|---|---|
| 2 h 网格、占用序列、9 种真实机型、工具规则、f1 | 原模型 `roster_sim.py`、`mtms.py`、`tools_model.py` |
| 站点限定机型、路程 δ_s、共享工具池 | 多站试点 |
| 全新启动、提前大修 | 启动代价试点 |
| 无限时域，用证书判定可行 | 证书试点 |
| 新：K_s ≥ 1 且各站可以不同 | 代码有参数 K，实验只用过 K = 1 |
| 新：机型单价 c_k | 代码有字段，没用过 |
| 新：两种初始条件写进同一个定义 | — |
| 新：实例分布，按训练/测试划分 | 学习型对照和调参需要 |
| 新：规模扩到 15–20 站 | — |

- 时变需求会破坏"最终周期"，证书就不能用了，除非需求本身是周期的。

## 3. 轮转周期松弛

### 3.1 统一形式（Dantzig–Wolfe 视角）
对每个机型 k 建一张轮转图 G_k：
- 节点是 (相位 i, 虚拟时刻 v)；
- 弧有三种：等待、值岗 (i, v) →(s) (i+1, v + nx_{k,i,s})、提前大修。

一台机器人的整个排班就是 G_k 上的一条路径 p。p 在 (s, t) 处的覆盖记为 a_p(s,t) ∈ {0, 1}，对工具的占用记为 b_p(j,t)。

主问题（松弛整数性，λ_p ≥ 0）：
```
min  Σ_k c_k N_k + Σ_j M_j
s.t. Σ_k Σ_{p∈P_k} a_p(s,t) λ_p = K_s     ∀ (s,t) ∈ 𝒯
     Σ_{p∈P_k} λ_p = N_k                   ∀ k
     工具流与值岗弧耦合，同时占用 ≤ M_j     （freshlb.py 现有写法）
```
稳态和全新启动只差路径集合 P_k 和时间集合 𝒯：

- **稳态**：
  - 𝒯 = Z_P，P_k 是 G_k 在 Z_P 上的闭环，也就是一台机器人的"轮转周期"；
  - LP 值与 P 无关，等于速率 LP（`fluid_lb`、`tool_lb`）。单机型时第三轮 §2.8 已经指出这一点；多机型加路程偏移的情形还要补一个简短证明（均匀流可行）。
- **全新启动**：
  - 𝒯 = [0, H)，P_k 是从 (0, v0_k) 出发的路径，越过 H 的部分不计；
  - 这就是 `freshlb.py` 的时间展开 LP，记作 LP_fr(H)。
- **允许提前大修**：在 G_k 上加重置弧，对应的值记为 LP^R。

对偶和定价：
- 对偶变量 π_{s,t} 就是槽权重。
- 定价问题是：在 G_k 的时间展开图上，求一台机器人能收集的最大权重（最长路动态规划）。
- 对偶可行的条件是：每型单台机器人的最大收集量 ≤ c_k（有工具时再加工具对偶项）。这就是第三轮引理 7 的多机型版本。
- 定理 8 是单机型时的一个显式对偶解。

### 3.2 下界链
- 不许提前大修：
  - R_rate ≤ 稳态整数下界 ≤ N*_st ≤ N*_fr；
  - LP_fr(H) ≤ N*_fr，且 LP_fr(H) 随 H 不减。
- 许提前大修：R_rate^R ≤ N*_st^R ≤ N*_fr^R，LP_fr^R(H) ≤ N*_fr^R ≤ N*_fr。
- 实际使用的下界：LB_fr = max(⌈LP_fr(H)⌉, 稳态整数下界)。只有 c_k、工具单价都是整数时才能取整。
- 注意：H 较短时，LP_fr(H) 可能低于 R_rate（新机器人额度满）；实测 H ≥ 2S–3S 后不再变化。

### 3.3 已有理论在哪里接上
| 理论结果 | 在松弛里的作用 |
|---|---|
| 命题 1（速率下界） | R_rate 的单机型特例 |
| 定理 8 + 有理证书 | LP_fr − R_rate 可以随 K 线性增长：全新启动松弛严格更强，而且差距随规模变大。这是选用全新启动松弛的理论理由 |
| 引理 7 | LP_fr 的对偶 = 槽权重，下界可以独立核对 |
| 定理 9 / 猜想 C4 | 两种松弛什么时候相等（启动代价为 0） |
| 定理 6.5、猜想 C5 | 单一机型池内取整损失 ≤ 1：剩下的差距主要来自多池、多站的耦合 |
| 分组损失定理 | 机型—站点分组的代价上界：解释为什么共享优于专点，也给出结构编码的上界 |
| 提前大修机证表 | LP_fr^R 往往降到稳态值。提前大修能拿回的空间 LP_fr − LP_fr^R 可以按实例算出来 |
| 铺砌、分圆判据、L = 2 闭式 | 不进这篇，留给单独的数学论文 |

### 3.4 还缺什么
1. 多机型下的三个小命题（不难，但要写出来）：
   - 稳态周期 LP = 速率 LP；
   - LP_fr(H) 关于 H 单调，并且对任何无限期可行排班都有效；
   - 对偶 = 多机型槽权重。
2. 下界到底有多紧：目前只有单站和 2 站两个实例被夹定。需要在 2–3 站带工具的实例上，用时间展开 ILP 加末段周期（`fresh_tail` 的做法）求精确或近精确上界，把 5–16% 的差距拆成"下界松"和"算法差"两部分。
3. 规模：8 站 s2、10 站的 LP 被 2 小时上限停掉。打算用列生成求同一个 LP（定价就是最长路动态规划），规模可以更大，对偶也直接给出规则要用的槽权重。
4. 从松弛解里读规则：目前只读出了机型配比、站点分工比例和提前大修流量（lpg、planf），还没有用到 LP 在时间维度上的流（每格、每站、每型该派多少）和对偶价格。
5. 取整：多机型时 ⌈LP⌉ 和整数最优差多少，没有任何理论结论，只能靠实验报告。
6. 稳态带提前大修的多站版本（ā* 推广到多站）没有算过。

## 4. 论文主线候选

### 主线 A（推荐）：松弛推导规则 + 规则偏离解码
用轮转周期松弛给出下界，再从松弛解推出默认规则；进化算法只在启动期内搜索对这条规则的稀疏偏离；证书保证永远可行。

- **核心贡献**
  1. MDRR 模型和轮转周期松弛：稳态与全新启动的统一 DW 形式，对偶 = 槽权重；全新启动松弛比速率松弛强，差距可以随规模线性增长。
  2. 由松弛推导的默认规则：按 LP 的时间展开流和机型—站点配比派工，按 LP 的提前大修流量错峰。这直接回应"RDD 是问题先验"：先验是从松弛推导出来的，不是手写的。
  3. 启动期偏离解码：基因只编码 [0, H_dev) 内的稀疏偏离（换候选机器人、提前或推迟大修、换工具）。H_dev 之后完全按默认规则运行，所以证书适用。这与精确解的结构一致：启动期不规则，之后按规则轮转。
  4. 证书适应度，作为组件。
- **对照**
  - 下界：LP_fr、LP_fr^R、R_rate；小规模的精确或近精确 ILP。
  - 精确方法：时间展开 ILP（小规模，带时限）、周期网络 ILP。
  - 手写规则：先到先派、相位平衡。
  - 只用默认规则，不进化。
  - 进化调规则：ES 调派工权重、GP 树（都已有）。
  - 原随机键 MOEA。
  - RDD + 手写默认规则（上一篇论文的做法）。
  - 学规则：PPO（带动作掩码的派工策略，在训练集上训练，在测试集上评估）；预算允许的话，再加 EoH 类的 LLM 打分函数。
- **消融**：默认规则的来源（手写 / LP 配比 / LP 时间流 / 对偶价格）；有无提前大修计划；偏离窗口 H_dev；偏离类型；证书与有限时域适应度；LP 时域 H。
- **风险**
  - LP 默认规则可能已经很好，偏离只能再省 0–1 个资源。那样论文的重心会变成"松弛 + LP 规则"，进化的作用变小。
  - 多站上提前大修的空间只有 0–3 个资源。
  - 如果下界本身松，就说不清离最优还有多远。
  - PPO 对照工程量大，而且要做到公平：同样的评估预算、同样的证书判定。
  - "LP 引导的启发式"在运筹里很常见，例如流体跟踪、Bertsimas–Sethuraman 的流体同步（需核实）。新意要落在三点上：无限时域、证书、偏离解码。
- **期刊**：IEEE TEVC（前提是方法点站得住、对照完整）；IEEE T-ASE（机器人排班应用 + 下界 + 方法）；EJOR / C&OR（偏运筹的写法）。

### 主线 B：派工策略的跨实例泛化（EA / GP / LLM / RL 同台）
- **核心贡献**：在实例分布上训练一个派工策略，用松弛对偶（槽权重、机型配比）当特征；在测试实例上直接使用，不再逐实例搜索；证书作为训练和评估时的可行性判据。
- **方法**：GP 或 LLM 生成打分函数，输入松弛特征；或者神经网络策略 + PPO。
- **对照**：PPO、A2C / actor-critic、GP 超启发式、EoH 类 LLM 方法、逐实例 ES、手写规则。
- **消融**：有无松弛特征、有无证书、训练分布的大小。
- **风险**
  - 赛道拥挤：GP 和 LLM 生成规则近两年很多。
  - 迁移试点在 4 站 s3 上基本无效。
  - RL 在"最少机队 + 无限时域"上奖励不好定义，需要外层循环来定台数。
  - 工程量最大，LLM 还要花钱。
- **期刊**：IEEE TEVC、IEEE TCYB、Swarm and Evolutionary Computation。

### 主线 C：全新机队的启动代价与提前大修错峰
- **核心贡献**：量化启动代价（线性增长定理；真实机型多出 13–27%）；全新启动松弛下界；提前大修错峰；LP 计划 + 进化派工。基本就是 10-26 笔记里的方案。
- **对照**：稳态下界、全新启动下界、允许提前大修的下界；不提前大修的进化派工；学出来的大修规则；按编号错峰；单型精确解。
- **消融**：只用计划、只用引导、两者合用。
- **风险**：进化算法的作用最弱，老师说的"规则放进解码器"体现不出来；多站上的收益小。
- **期刊**：IEEE T-ASE、C&OR、IISE Transactions。

### 三条主线的关系
- A 包含 C 的大部分内容。如果偏离解码在实验里没有明显好过 LP 默认规则，就退回 C 的写法，已经做的工作都能用上。
- B 的组件（ES 调权重、GP、PPO）放进 A 当对照，不当贡献。
- 铺砌理论不进这篇。

## 5. 确认后的第一步（只是建议）
- E1 拆差距：在 2–3 站带工具的实例上，用时间展开 ILP 求精确或近精确解，看 5–16% 的差距里有多少是下界松。
- E2 测默认规则本身：LP 跟踪规则（不进化）在全部现有实例上跑一遍，和 lpgplan 比。
- E3 扩规模：列生成版的全新启动 LP，补算 8 站 s2、10 站，再扩到 15–20 站。

这三项的结果决定主线 A 能不能成立。
