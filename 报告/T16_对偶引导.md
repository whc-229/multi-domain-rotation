# T16 对偶引导偏离位置（2026-11-02）

只用训练实例：m ∈ {4, 6, 8, 10} 的 48 个实例，β ∈ {0, 0.5, 1}，种子 0–2，共 432 个 RDD-FD 作业，全部可行。

## 结论先看
- **β > 0 平均只略好一点，而且不稳定。**
  - β = 1 与 β = 0 比（同一实例、同一种子）：少 42 对、同 87 对、多 15 对，平均 −0.14 个资源（全体平均约 123 个，约 0.1%）。
  - β = 0.5：少 29、同 102、多 13，平均 −0.09。
  - 各取 3 个种子里最好的值比，β = 1 是 12 / 33 / 3，平均 −0.15。
  - m = 8 K12 上反而变多：β = 1 平均 +0.83（同种子），只有这一组是 β = 1 明显更差。
  - 符号检验（只作参考）：β = 1 同种子 p = 0.0005，β = 0.5 p = 0.02；按实例最好值，β = 1 p = 0.035，β = 0.5 p = 0.08。
- **严格证明数没有提高**：β = 0、0.5、1 分别是 85、74、80 / 144。其余都是 60 万格复核 0 缺岗。
- **偏离落点按设计跟着对偶走，但均匀搜索本身并不偏向对偶价格高的决策。**
  - 对偶价格高度集中在启动最初 0.25·S_max：在 [0, 2·S_max) 的价格总量里占 37–46%（按 m）。
  - β = 0 时，最终解里激活的偏离在时间上大致均匀（每 0.25·S_max 一段 11–16%）。在本次运行全部窗口决策里，它们的对偶权重平均分位是 0.51–0.53，与随机放置一样。
  - β = 1 时，41–49% 的偏离落在最初 0.25·S_max，与对偶价格的分布接近；平均分位升到 0.74–0.77。
  - 也就是说："大修扎堆、价格高"的地方，并不是搜索自己找出来的有用偏离位置。β > 0 把偏离推到那里，只带来很小的改进。
- **建议**：不把它作为独立的第六个部件 C6 进入消融（见"待确认"）。

## 1. 设定
- 默认规则 `fresh_rlp_w`（严格窗口 planW = 2·S_max，后备补足时域 `hsfb`）+ `resetopt`。ρ = 0.1、q_on = 0.4、(4 + 12)、T_eval = 6·S_max、台数互换 0.5、stall 30，与 T12 相同。
- 决策权重 w_i = Σ_{u∈[t, t+d)} max(π_{s,u}, 0)。π 取 LP_fr^Rw(4S) 的覆盖对偶：`results/T6_duals/<实例>__frRw__m4.npz`，数值失败的实例用 `__retry1`。
  q_i = (1 − β)/N_dev + β·w_i/Σw；位置基因 p 映射到第一个累积 q > p 的决策。β = 0 时不传对偶文件，与原 RDD 逐位相同。
- 墙钟限时：m = 4 为 300 秒，m = 6 为 600 秒（按 T11 实测：1000 代最长 50 秒、128 秒）。
  m = 8、10 为 1 小时：T12 的 36 个运行里，m = 8 有 31 个、m = 10 有 32 个在 1 小时内找到最终解（`results/T16/tlim.json`、`tlim_basis.json`）。
- 代码：`code/t16_job.py`、`code/t16_check.py`、`code/t16_summary.py`；结果 `results/T16/jobs/`、`results/T16_dual_guided.jsonl`（逐作业，含每个激活偏离的 (t, s, d, w, 分位)）。

读法：
- 大修扎堆、对偶价格高的时段是启动最初的 0.25·S_max，所有机器人在这段同时从新状态出发。
- 均匀搜索留下的偏离在时间上几乎是平的，并不集中在这一段。β = 1 时偏离的分布与对偶价格基本对上，但资源数只少了一点。
- 可能的原因（未验证）：LP 的覆盖对偶衡量"哪个站、哪个时刻缺覆盖"，而偏离的效果要经过后面整条轨迹（谁在什么时候进大修、窗口后的规则能否接上）才体现。偏离位置的价值不完全由局部的覆盖紧张程度决定。

## 5. 核对
- 实现核对（`code/t16_check.py`，开跑前）：24 组 0 不一致。包括 β = 0 与原 RDD 逐位相同、权重与 cdf 逐个相同、带 cdf 的解码 C++ 与 Python 逐字段相同。
- 作业内核对：最终解用 `rost5 judge`（带同一个 cdf）重新判定，逐字段相同 432 / 432；抽样 T_eval 缺岗与 `rost5 eval` 相同 17 280 / 17 280。
- 汇总时：参考实现解码出的激活偏离数与 rost5 的 n_active 相同 432 / 432；提前大修都在 [0, 2·S_max) 内 432 / 432。

## 6. 技术选择
- m = 8、10 限时 1 小时：按 10-30 晚审核"多数运行 1 小时内找到最终解就用 1 小时"，由 `code/t16_tlim.py` 在 T12 结束时自动定。
- 偏离位置的对偶权重按"偏离实际所在的决策"重新算，而不是按默认规则下的决策序列。偏离会改变后面的轨迹，同一个下标在最终解里对应的 (s, t) 可能与默认规则不同。
- 对照组用同一次运行的全部窗口决策，这样不受各实例决策数、价格量级不同的影响。
